# Opportunity Revenue reference template

This directory contains a source-control-friendly extraction of the user's
`Revenue Opportunities.pbix` reference report.

Included:

- Report structure and page definitions.
- Visual configurations, bindings, layout, and interactions.
- The Classroom theme and report-owned SVG resources.

Excluded:

- Embedded data and semantic-model storage.
- Credentials and local Power BI cache files.
- Fabric workspace, report, and semantic-model identifiers.

Use the template to understand the intended Overview, Detail, and Tooltip
composition. Do not copy its legacy `filledMap`; use `azureMap` as required by
the parent guideline.
