# Random Revenue Pulse workspace

This workspace contains a new Power BI report artifact created for pull-request
review against the Opportunity Revenue report standard.

`Random Revenue Pulse.Report`:

- Uses the existing NYC Taxi semantic model connection.
- Preserves the required Overview, Detail, and Tooltip architecture.
- Includes KPI cards, a slicer, Azure Map, ranked comparisons, trend analysis,
  detail matrices, and a compact hidden tooltip.
- Reuses the repository's validated Taxi Revenue PBIR structure while giving
  the report its own Fabric display name and title.
